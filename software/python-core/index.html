    Python Core & Python Packages¶

    Overview¶

    Approach¶

    Glasgow TRE allow Python development is based on a Python Management approach, which allows user to tailor their their Python environments according to their specific needs.

    Management¶

    This is based on Astral's uv Python manager. Users can install, manage, and switch between multiple Python versions and their associated packages.

    Python Builds¶

    Selected Python builds are sourced from astral-sh/python-build-standalone and hosted in an internal mirror. uv then is then downloading the selected version according to your request.

    Supported Python Versions

    please refer to the Available Python Releases section for a list of available versions.

    Available Packages¶

    Python package managers are preconfigured configured to use our internal PyPA mirror. This includes pip and uv.

    IDE Support¶

    Environments made with uv are fully compatible with modern IDEs such as VS Code. This creates an ideal enviroment for developers who want to write and test their Python code.

    Note

    Jupyter notebooks use the same underlying infrastructure but are pre-configured and ready to be used.

    Additional Python Packages¶

    If you need additional packages, please submit a package request ticket through your Glasgow TRE representative or send an email to the helpdesk at tre@glasgow.com.

    After we review your request, the packages will be made available to all users and projects.

    Information Needed

    Make sure to include the library name, requested version, and analytical rationale.
