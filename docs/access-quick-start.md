If you have been approved for a University of Glasgow Trusted Research Environment (UoG TRE) project - congratulations and welcome!

This Handbook has guides and instructions for various features in the TRE, such as installing new software, transferring data to the TRE or requesting outputs.

For new users, the quick start guide is below.

# ACCESS QUICK START

For new TRE Users being onboarded to the platform, you will receive an email asking you to sign-up to our Terms of Users
Once you have signed up, you will receive a welcome email with detailed access instructions
Separate to this email, you will receive a username and password in separate emails to your registered institutional email accounts
Install FortiClient and start your VPN using the credentials
Download the .RDP file at your personal URL as per the instructions in '2'
When connected to the VPN, start the remote computer using the .RDP, authenticating as required
A remote Windows session will start with your data directory and personal working file directory mounted

# SUPPORT

Refer to the instructions in '2', the Handbook here or email tre@glasgow.ac.uk for more help.
